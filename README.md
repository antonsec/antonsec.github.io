# Pierre Anton’s portfolio

[Visit the portfolio](https://pierreanton.com/)

A static portfolio featuring Air Gesture Interface and Smart File Organizer. It uses HTML, CSS, and vanilla JavaScript.

## Local preview

From the repository root, run:

```sh
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000/). The About Me page is at `/about-me/`, and `/about.html` redirects there for older links.

## Deployment

GitHub Pages publishes from the root of `main`. The `CNAME` file sets the custom domain, `pierreanton.com`.
